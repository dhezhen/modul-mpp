# Modul 10: Proyek Akhir, Pengujian, dan Rilis Multiplatform

1. Buatlah Projek Aplikasi Sederhana dengan ketentuan sebagai berikut:
         1. Tema Aplikasi

Mahasiswa bebas menentukan tema aplikasi yang akan dibuat menggunakan Flutter, tetapi harus memiliki tujuan dan pengguna yang jelas . Misalnya aplikasi tugas, keuangan, catatan, inventaris, kuliner, wisata, dan sebagainya.

         2. **Design Aplikasi**

Membuatkan Design Aplikasi yang akan dibuat, Adapun design aplikasi yang dibuat dengan menggunakan tools pendukung seperti Figma atau Tools Sejenisnya.

         3. **Fitur Aplikasi**

Berikut fitur yang harus ada:

- Minimal 5 Halaman
- Terdapat Fitur Login, register, logout
- Terdapat Crud
- Terdapat Navigasi
- Terdapat halaman Profile pembuat
- Terdapat Homepage/Dashboard Menu
- Responsive UI
- Menampilkan data dari API Publik (lebih bagus)
- Firebase Auth (optional)
2. File projek akan di unggah ke github masing-masing dan website portofoliofkom.my.id
3. Projek dipresentasikan saat uas praktikum berlangsung
4. Poin Penilaian:
   1. Kesesuaian dengan ketentuan (25)
   2. Fungsi & Fitur (20)
   3. UI/UX (25)
   4. Presentasi (30)
